# 消消乐（Match-3 微信小游戏）

一个用纯 JavaScript 写的消除类休闲小游戏，同时支持 **微信小游戏** 与 **网页浏览器** 两种运行方式，核心逻辑共用同一份代码。

## 特性

- **经典三消**：点击交换相邻方块，三个及以上同色自动消除并连锁下落
- **流畅动画**：交换 / 消除 / 下落全程缓动，连击飘字反馈
- **音效**：Web Audio 实时合成（命中 / 消除 / 连击 / 特殊触发），零音频素材依赖
- **特殊方块**：4 连生成直线消除块（清整行 / 整列），5 连生成炸弹（清 3×3），可连锁引爆
- **8 关递进**：目标分与步数逐步加码
- **障碍系统**：冰块（敲掉层数）、锁链（锁住糖果，相邻消除震碎）
- **多玩家档案**：同一台设备可建多个玩家，进度各自独立存储，互不影响
- **进度保存**：按玩家自动续关

## 目录结构

```
match3-wechat/
├── game-core.js          # 平台无关核心引擎（棋盘/消除/连锁/特殊方块/关卡/障碍）
├── profile-store.js      # 平台无关的「多玩家档案」存储（每个档案一个数据文件）
├── game.js               # 微信小游戏入口（Canvas 渲染 + 音效 + 档案选择界面）
├── game.json             # 小游戏配置
├── project.config.json   # 微信开发者工具项目配置
├── web/
│   └── index.html        # 网页版本（单文件自包含，双击即玩）
└── README.md
```

## 运行方式

### 网页预览（最快）

直接用浏览器打开 `web/index.html` 即可游玩，无需任何依赖或服务器。

### 微信小游戏

1. 打开微信开发者工具 → 导入项目
2. 目录选择 `match3-wechat/` 整个文件夹
3. AppID 填 `touristappid`（游客 / 测试号）或你自己的小游戏 AppID
4. 编译后即可在模拟器或真机预览

## 玩法

- 进入游戏先**选择玩家**（或新建玩家），每个玩家有独立进度
- 点击一个方块，再点击相邻方块进行交换
- 凑成 3 个及以上同色即消除并加分，连锁有连击倍率
- 4 连 / 5 连会生成特殊方块，制造更大范围消除
- 在含冰块的关卡中，需达成目标分数 **且** 敲光所有冰块才能过关
- 步数耗尽未达标则本关失败，可重开继续
- 游戏中点「切换玩家」可返回档案界面，新建 / 删除玩家

## 数据存储（多玩家档案）

每个玩家的数据**互相独立、各自一份文件**：

- **微信小游戏**：存于 `wx.env.USER_DATA_PATH/profiles/` 下的真实文件（`<id>.json`）。
  该目录本身按微信用户隔离，天然做到「每个用户数据分开」；
  另有 `profiles/index.json` 记录档案列表与当前选中档案。
- **网页版**：浏览器无法直接写磁盘，改用 `localStorage` 以 `m3fs:profiles/<id>.json`
  键的形式模拟「每档案一个文件」。

升级自旧版本时，原有的单存档（`match3_level`）会自动迁移为第一个档案，进度不丢失。

## 技术说明

- 核心引擎 `game-core.js` 与档案存储 `profile-store.js` 均不依赖任何平台 API：
  微信端用 `require` 引入，网页端内联同一份代码，两端行为一致
- 存储层通过注入 adapter 适配平台：微信用文件系统、网页用 localStorage
- 动画采用基于时间步的状态机（`update(dt)` 驱动），各入口每帧调用
- 音效使用 Web Audio API 实时合成（微信端 `wx.createWebAudioContext`），无需音频文件
- 关卡、障碍、特殊方块均在 `game-core.js` 中以配置 + 数据驱动，便于扩展
